# Черновик уведомления о приватности

Этот текст — техническая заготовка для проверки владельцем проекта и юристом, а
не готовое юридическое заключение.

При нажатии «Я ИДУ» приложение создаёт случайный идентификатор одной попытки
RSVP. В локальном хранилище браузера сохраняются только версия формата, статус
`pending`/`confirmed` и этот случайный идентификатор. Telegram ID, имя,
username, телефон, фотография и данные профиля Telegram приложением не
запрашиваются и не передаются серверу.

Сервер получает случайный идентификатор попытки, хранит его для предотвращения
случайного повторного учёта и увеличивает общий счётчик. Организатор получает в
Telegram только сообщение `+1`. После закрытия RSVP набор случайных
идентификаторов удаляется; итоговое агрегированное число может быть сохранено.

При обычном сетевом соединении IP-адрес и HTTP-заголовки технически доступны
Telegram, сетевому оборудованию и хостинг-провайдеру, даже если приложение не
использует их и не записывает в свою базу. Владельцу проекта необходимо отдельно
проверить журналы, резервные копии, DDoS-защиту, CDN и условия обработки данных
у Timeweb Cloud и Telegram.

Перед публикацией сюда необходимо добавить сведения о владельце проекта,
контакты, цель и срок обработки, порядок обращения и иные формулировки,
рекомендованные профильным юристом.
