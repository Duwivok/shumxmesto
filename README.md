# SHUM Mini App

Статический лендинг Telegram Mini App и вспомогательные материалы для публикаций бота.

## Как устроена публикация

- GitHub хранит исходники проекта.
- GitHub Pages публикует только содержимое каталога `site/`.
- Workflow `.github/workflows/deploy-pages.yml` запускается автоматически после изменений в `site/` в ветке `main`.
- Telegram открывает адрес GitHub Pages, настроенный для Mini App в BotFather: `https://duwivok.github.io/shumxmesto/`.
- Сервер используется только для запуска скриптов бота и не участвует в раздаче сайта.

## Структура

- `site/` — файлы сайта, публикуемые в GitHub Pages.
- `bot/scripts/` — скрипты подготовки и отправки Telegram-публикаций.
- `bot/templates/` — шаблоны публикаций.
- `.github/workflows/deploy-pages.yml` — автоматическая публикация `site/`.
- `deploy.ps1` — локальная проверка, commit и push в `main`; дальнейшую публикацию выполняет GitHub Pages.

## Секреты

Секреты, рабочие файлы `.env` и приватные ключи в Git не сохраняются. Для запуска publisher требуется переменная окружения `TELEGRAM_BOT_TOKEN`; файл `.env.example` содержит только пустой пример.

## Публикация сайта

Обычный `git push` изменений каталога `site/` в ветку `main` автоматически запускает GitHub Pages workflow. Сборка сайту не требуется: каталог `site/` загружается как готовый Pages artifact.

Для проверки, создания коммита и отправки изменений одной командой можно использовать:

```powershell
.\deploy.ps1 "Описание изменений"
```

Скрипт не подключается к серверу и не перезапускает бота. Статус публикации отображается во вкладке **Actions** репозитория, а готовый сайт доступен по адресу `https://duwivok.github.io/shumxmesto/`.

Если Pages ещё не активирован, один раз выберите в настройках репозитория **Settings → Pages → Build and deployment → Source: GitHub Actions**.
