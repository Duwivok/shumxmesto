# SHUM Mini App

Репозиторий статического лендинга и локальных вспомогательных материалов для публикаций.

## Структура

- `site/` — публичный лендинг, публикуемый в GitHub Pages.
- `bot/scripts/` — локальные скрипты для подготовки и отправки публикаций.
- `bot/templates/` — шаблоны публикаций.
- `.github/workflows/deploy-pages.yml` — автоматическая публикация содержимого `site/` в GitHub Pages при отправке изменений в ветку `main` или ручном запуске workflow.

## Секреты

Секреты и рабочие файлы `.env` в Git не сохраняются. Переменные окружения задаются локально; файл `.env.example` содержит только пустой пример имени переменной. Перед каждым коммитом следует проверять, что токены, пароли и другие учётные данные не попали в отслеживаемые файлы.

## Публикация

GitHub Actions загружает в Pages только каталог `site/`. Локальные скрипты и шаблоны из `bot/` в опубликованный сайт не входят.
