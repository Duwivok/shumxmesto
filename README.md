# SHUM Mini App

Статический лендинг и локальные вспомогательные материалы для Telegram-публикаций.

## Структура

- `site/` — публичный лендинг, публикуемый в GitHub Pages.
- `bot/scripts/` — локальные скрипты для подготовки и отправки публикаций.
- `bot/templates/` — шаблоны публикаций.
- `deploy.ps1` — commit, push, безопасное обновление сервера и проверка сайта одной командой.

## Секреты

Секреты, рабочие файлы `.env` и приватные ключи в Git не сохраняются. Переменные publisher хранятся на сервере в `/etc/shumxmesto/publisher.env`; файл `.env.example` содержит только пустые примеры переменных.

## Публикация

На сервере проект расположен в `/srv/shumxmesto`, а Nginx отдаёт статические файлы непосредственно из `/srv/shumxmesto/site`. Сборка не требуется.

Для очередного обновления из корня проекта выполните:

```powershell
.\deploy.ps1 "Описание изменений"
```

Скрипт проверяет ветку и секреты, создаёт commit, выполняет push в `main`, запускает на сервере `git pull --ff-only` и проверяет HTTP 200.
