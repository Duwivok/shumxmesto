# Стекло таймера · версия 6

> В `site/` включены только файлы для сайта, маски и описание регистрации.
> Крупные исходники, SVG, карты, скрипты и предпросмотр остаются в исходном
> архиве `monitor-glass-v6.zip`. Подключение описано в `INTEGRATION.md`.

Три накладки с фотографической фактурой стекла: мягкими неоднородными отражениями, дымчатой тонировкой, тонкими потёртостями и мелкими повреждениями у краёв. Для каждого экрана подготовлена отдельная фактура. В маленьком размере основную роль играют отражение и тонировка; тонкие царапины различимы при увеличении.

## Подключение

Замените три старых PNG файлами из папки `web/`. Координаты, маски, размеры и перспектива сохранены из v3–v5. Применяйте обычное наложение (`normal` / `source-over`), `opacity: 1`, `pointer-events: none`. Полупрозрачность находится внутри самих PNG.

| Экран | Файл для сайта | Размер | Крупный файл |
|---|---|---|---|
| Дни — верхний левый | `web/glass-top-left.png` | 267 × 210 px | `master/glass-top-left.png`, 1070 × 840 px |
| Часы — верхний правый | `web/glass-top-right.png` | 246 × 200 px | `master/glass-top-right.png`, 985 × 801 px |
| Минуты — нижний правый | `web/glass-bottom-right.png` | 242 × 218 px | `master/glass-bottom-right.png`, 968 × 871 px |

Старые накладки удаляются при замене. Если браузер сохраняет прежний результат, измените версию URL изображений.

## Координаты и слои

Общий фрейм — **390 × 720**. `layout.json` задаёт прямоугольник размещения каждого PNG (`x`, `y`, `width`, `height`) и его процентный аналог `css_percent`. Размер PNG в пикселях не равен размеру элемента на странице. Перспектива уже встроена: повторно искажать готовое стекло не нужно.

Снизу вверх: исходная сцена → отсветы на корпусах → фон экрана / помехи → анимированные цифры и звёзды → их синхронное свечение → стекло. Содержимое экрана ограничивается его маской. Белая маска используется только для обрезки, не как видимый слой.

Статичное стекло смешивается с текущим кадром цифр через альфа-канал. Само по себе оно не создаёт синхронное динамическое свечение. Исходные анимированные цифры этим набором не изменяются.

Минуты сохраняют отдельный нижний правый контур с собственным наклоном из v3. Он был восстановлен из более ранней корректной маски, поскольку в новых присланных SVG часы и минуты дублировались. Происхождение геометрии и расчёт сохранены в `layout.json` и `source/registration.json`. Погрешность регистрации контрольных точек не означает измеренную точность отсутствующей новой маски минут.

## Остальные файлы

- `master/`: крупные прозрачные PNG.
- `editable/`: SVG-контейнеры со встроенной PNG-фактурой; это **не полностью векторное стекло**. Их можно использовать без внешних ссылок на изображения.
- `masks/`: точные белые маски без видимого розового оттенка, без изменений из предыдущего набора.
- `glass-all-390x720@4x.png`: три накладки на общем прозрачном фрейме 1560 × 2880 px. Используется вместо отдельных PNG при совпадении привязки фоновой сцены к фрейму 390 × 720.
- `preview/comparison-v6.png`: предварительная реконструкция v5 и v6 на присланном скриншоте. При сравнении учтён прежний слой стекла; из-за приблизительной привязки скриншота это не заменяет проверку сайта после подключения.
- `preview/three-surfaces-v6.png`: все три накладки на тёмной подложке, добавленной только для просмотра.
- `source/maps/`: непрозрачные исходные карты отражений, созданные генерацией. **Их не подключают поверх цифр**. При экспорте интенсивность карты преобразуется в полупрозрачное отражение, затем добавляется слабая тонировка.
- `source/build.cjs`: код проекции и экспорта; `source/GENERATION.md`: описание и запросы генерации.

## Пересборка

Из корня набора: `node source/build.cjs` (нужен Node.js и sharp). Скрипт читает `layout.json` и три карты из `source/maps/`, преобразует их в RGBA, проецирует по четырём углам каждого экрана и создаёт PNG, SVG-контейнеры и общий атлас. Уменьшение выполняется из крупных файлов; прозрачность дополнительно ограничивается точной маской.

Проверены шесть отдельных PNG: настоящая прозрачность, отсутствие полностью непрозрачных пикселей и выхода за контур, размеры. Геометрия и маски совпадают с v5. Сайт автоматически не изменялся.
