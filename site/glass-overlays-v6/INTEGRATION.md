# Подключение стекла v6 в Mini App

Текстуры из `monitor-glass-v6.zip`: отдельные полупрозрачные отражения,
дымчатая тонировка и потёртости для каждого монитора. Геометрия, маски
и регистрация полностью совпадают с v3.

`layout.json` — источник координат всех трёх экранов в сцене 390 × 720.
Текущий `backgrounds/home.png` имеет размер 1560 × 2880, то есть масштаб 4×.
`perspective.js` читает JSON и использует его одновременно для:

- четырёх углов перспективы цифр каждого экрана;
- обрезки содержимого через CSS `clip-path`;
- положения и размеров трёх PNG из `web/`.

PNG размещаются по прямоугольникам без дополнительной перспективы.
SVG из `masks/` сохранены для сверки; их геометрия совпадает с JSON.
Рабочие копии в `../mask-timer/` обновлены из того же архива.
Контур минут восстановлен автором набора из прежней геометрии, что отмечено
в `layout.json` и `source/registration.json`.

Порядок от фона к зрителю: исходная сцена → отсвет на корпусах → фон экрана
→ анимированные цифры и звёзды с синхронным светом → стекло.

Существующий `glow/timer-glow.webm` содержит три внешних ореола с прозрачной
серединой. Он используется как отсвет на корпусах; его исходный прямоугольник
390 × 240 при y = 419.5 переносится в новую компоновку матрицей регистрации
из JSON. Внутри экранов используется отдельный общий ролик
`timer-backgrounds-v1/web/timer-backgrounds.webm` на фрейме 390 × 720.
Его маски и перспектива уже встроены и совпадают со стеклом v6.
Прежние градиенты удалены. Подробности — в `../timer-backgrounds-v1/INTEGRATION.md`.
Для Apple-устройств и ошибки воспроизведения сохранён WebP-вариант ореолов.
Видео приостанавливается при уходе с главной страницы и скрытии вкладки.

Дополнительный свет создаётся SVG-фильтром `timer-digit-light` из текущего
`SourceGraphic`. Резкая анимация и её размытие используют один кадр;
отдельные копии анимированных WebP не запускаются. Результат обрезается
маской и находится под стеклом.

Область цифр уменьшена до 80% прежнего размера: 67.2% × 67.2% вместо
84% × 84% от локальной плоскости экрана. Её верхняя граница находится
на 4% высоты, а центр — на 37.6%. Нижняя часть оставлена для будущих
подписей. Размер и положение задаются до применения перспективы,
поэтому обе цифры сохраняют наклон и сужение соответствующего монитора.

Начальные настройки:

- Стекло: `opacity: 1`, `mix-blend-mode: normal`, `pointer-events: none`.
- Отсвет корпусов: `.timer-glow-layer.is-ready`, `opacity: 0.32` в `styles.css`.
- Свет цифр: `stdDeviation="3"`, сила альфа-канала `0.45` в фильтре в `index.html`.

Для проверки только совмещения установите `data-effects="off"` у
`[data-countdown]` в инструментах разработчика. Останутся исходный фон,
цифры и стекло. Рабочее значение — `on`.
