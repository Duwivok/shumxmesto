# Анимированная засветка внутри экранов

Полный исходный архив распакован в `../../timer-backgrounds-v1/`.
Для сайта скопированы только общий `web/timer-backgrounds.webm` и его
прозрачный `preview/poster-all.png`. Отдельные ролики и MP4 не подключены.

Общий WebM: 780 × 1440, 8 секунд, без звука. Маски, положение и перспектива
встроены в видео и совпадают с `glass-overlays-v6/layout.json`.
Элемент `.timer-screen-backgrounds` занимает весь фрейм сцены 390 × 720:
`inset: 0; width: 100%; height: 100%`. К нему не применяются матрица
перспективы или дополнительная маска.

Порядок слоёв: сцена → внешнее свечение → общий фон экранов → цифры
и их синхронное свечение → стекло v6. Прежние непрозрачные градиенты
в отдельных экранах удалены, чтобы видео оставалось видно под цифрами.

Настройки видео: `autoplay`, `loop`, `muted`, `playsinline`, `opacity: 1`,
`mix-blend-mode: normal`, `pointer-events: none`.
`timer-background.js` приостанавливает воспроизведение вне главной страницы
и при скрытии вкладки, затем продолжает его. Если воспроизведение недоступно
или декодер теряет прозрачность, используется статичный прозрачный постер
из того же архива. MP4 для этой цели не используется.

Размер, положение и исходные файлы цифр сохранены. `data-effects="off"`
у `[data-countdown]` скрывает новый фон вместе с остальными эффектами
для проверки совмещения цифр и стекла.
